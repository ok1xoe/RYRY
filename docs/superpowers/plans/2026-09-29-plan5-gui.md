# Plán 5: GUI (SwiftUI) – implementační plán

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nativní macOS aplikace `mmtty4mac.app` s rozložením podobným MMTTY: vodopád/spektrum s laděním kliknutím, okna příjmu a vysílání, řada maker F1–F12, QSO okno s předchozími spojeními, minilog, nastavení a spuštěná API.

**Architecture:**
- **Aplikace:** SwiftPM executable target `MMTTY4MacApp` (SwiftUI `App`) a skript `scripts/make-app.sh`, který sestaví `.app` bundle (Info.plist s `NSMicrophoneUsageDescription`, ad-hoc podpis).
- **Logika bez UI:** target `AppUI` obsahuje `@MainActor @Observable AppModel`. Ten drží `AppController`, API servery a odvozený stav pro zobrazení, a je testovatelný bez okna.
- **Pohledy:** target `AppViews` obsahuje SwiftUI views. Kreslení vodopádu je přes `CGImage` s posuvným bufferem, vstupem je `SpectrumFrame` z Engine (10–20 fps).
- **Změna nastavení:** `AppModel.applySettings` zastaví API a `AppController` a postaví nový Engine, protože ten je po `stop()` jednorázový.

**Tech Stack:** SwiftUI (macOS 14), AppKit (`NSTextView` pro RX text přes `NSViewRepresentable`), CoreGraphics.

**Spec:** `docs/superpowers/specs/2026-09-28-mmtty4mac-design.md` (sekce 8)

## Global Constraints

- macOS 14+, Swift 6 (UI na `@MainActor`), LGPL v3. Build a testy s `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Žádná logika v pohledech. Vše jde přes `AppModel` → `AppController`.
- Vodopád nesmí blokovat hlavní vlákno: převod spektra na řádek pixelů je čistá funkce (testovaná) a kreslí se jen hotový `CGImage`.
- Klávesy: F1–F12 = makra, Esc = okamžitě RX (`rxNow`), ⌘T = TX/RX přepínač, ⌘L = zalogovat QSO.

## Review Focus

1. **Aplikace bez oprávnění k mikrofonu nebo bez zvukového zařízení** → srozumitelná hláška v UI, aplikace běží dál (příjem nefunguje, nastavení jde otevřít). Test v Task 1 (`AppModel` s `FakeAudioBackend(failStart)`).
2. **Změna nastavení během vysílání** → nejdřív bezpečně RX a PTT off, pak restart. Test v Task 1.
3. **Rychlý proud znaků** (300 Bd, dlouhé relace) → RX text omezený na 200 000 znaků, UI nezamrzne. Test v Task 1 (limit).
4. **Kliknutí na slovo v RX textu** (`OK1ABC/P`, `599`, `HANS`) → rozpozná značku, report i jméno a vloží je do správného pole. Test v Task 2.
5. **Obsazené porty API při startu aplikace** → varování v UI, aplikace běží. Test v Task 1.

### Task 1: AppModel (stav pro UI)

**Files:** `Sources/AppUI/{AppModel,WaterfallRenderer,WordClassifier}.swift`, `Tests/AppUITests/*.swift`

```swift
@MainActor @Observable public final class AppModel {
    public init(settingsStore: SettingsStore, profileStore: ProfileStore, makeBackend: @escaping () -> AudioBackend = { CoreAudioBackend() },
                makeRig: @escaping (RigSettings) -> Rig = AppModel.defaultRig)
    public private(set) var settings: AppSettings
    public private(set) var state: EngineState
    public private(set) var rxText: [RxRun]              // úseky textu {text, echo}, limit 200 000 znaků
    public var txDraft: String
    public private(set) var signalLevel: Double, squelchOpen: Bool
    public private(set) var mark: Double, space: Double
    public private(set) var rig: RigStatus?
    public var qso: QSOFields                              // obousměrně (setQSOField)
    public private(set) var previousQSOs: [QSORecord]      // pro aktuální značku
    public private(set) var logRecords: [QSORecord]
    public private(set) var messages: [String]            // chyby a varování pro UI
    public private(set) var apiStatus: String
    public private(set) var waterfall: WaterfallRenderer
    public func start() async; public func stop() async
    public func applySettings(_ s: AppSettings) async      // RX, PTT off, restart
    public func toggleTx() async; public func rxNow() async; public func tune() async
    public func sendDraft(mode: SendMode) async            // char/word/line
    public func runMacro(_ i: Int) async
    public func setParam(_ id: String, _ v: ParameterValue) async
    public func param(_ id: String) -> ParameterValue?
    public func tune(toMarkHz: Double) async               // klik ve vodopádu
    public func logQSO() async; public func clearQSO() async
    public func updateLog(_ r: QSORecord) async; public func deleteLog(_ id: UUID) async
    public func insertWord(_ w: String) async              // klik na slovo → pole QSO podle WordClassifier
}
public struct WaterfallRenderer { public init(width: Int, height: Int); public mutating func push(_ f: SpectrumFrame, fromHz: Double, toHz: Double); public var image: CGImage? }
public enum WordKind: Equatable { case call, rst, name, other }
public enum WordClassifier { public static func classify(_ w: String) -> WordKind }
```
**Testy:**
- Start s `FakeAudioBackend(failStart = true)` → zpráva v `messages` a aplikace běží (Review Focus 1).
- `applySettings` během TX → nejdřív RX a pak restart; stav a porty z nových nastavení (Review Focus 2).
- RX text omezen na 200 000 znaků (Review Focus 3).
- Obsazený port API → varování a `apiStatus` (Review Focus 5).
- `tune(toMarkHz:)` nastaví mark.
- `sendDraft(.word)` pošle jen dokončená slova.
- `WaterfallRenderer.push` posune řádky a barva odpovídá úrovni.

### Task 2: WordClassifier a vkládání do QSO

- Značka: regex ITU prefix + číslice + suffix (`OK1ABC`, `DL1ABC/P`, `2E0XYZ`, `VK2/G4ABC`). RST: `[1-5][1-9][1-9]` (+ číslo závodu). Jméno: 2–10 písmen, ne Q-kód ani běžná zkratka (CQ, DE, TU, PSE, RST, UR, …).
- `insertWord`: značka → call, RST → rstRcvd, jméno → name. Obojí se pozná podle klasifikace.
- Testy pro sadu slov z Review Focus 4.

### Task 3: Pohledy (SwiftUI)

**Files:** `Sources/AppViews/{MainView,TopBar,WaterfallView,RxTextView,TxEditor,MacroBar,QSOPanel,LogWindow,SettingsView,MacroEditor}.swift`

- `MainView`: `VSplitView` s pořadím TopBar, Waterfall, RX, TX, MacroBar a QSOPanel vpravo.
- `WaterfallView`: `Canvas` s obrázkem a kurzory mark/space. Klik naladí, kolečko mění squelch.
- `RxTextView`: `NSTextView` (read-only). Echo textu je jinou barvou, klik na slovo volá `insertWord`, auto-scroll.
- `TxEditor`: pole pro text a přepínač odesílání (znak, slovo, řádek). Enter odešle.
- `MacroBar`: 12 tlačítek s názvy, kontextové menu Upravit (MacroEditor).
- `QSOPanel`: pole Call, Name, QTH, Loc, RST s/r, Nr s/r, Exch, Notes, tlačítka Log a Clear, seznam předchozích QSO.
- `LogWindow`: `Table` (čas, značka, pásmo, frekvence, RST, jméno, QTH), hledání, dvojklik = úprava v sheetu, mazání s potvrzením.
- `SettingsView`: záložky Stanice, Zvuk (výběr zařízení z `AudioDevices`), PTT/FSK (porty z `POSIXSerialPort.availablePorts()`), Rig, Modem (generované z `parameterDescriptors`), Makra, Log, API.

### Task 4: Aplikace a bundle

**Files:** `Sources/MMTTY4MacApp/App.swift`, `scripts/make-app.sh`, `Resources/Info.plist`

- `@main struct MMTTY4MacApp: App`: `WindowGroup` (MainView), `Window("Log")`, `Settings { SettingsView }`, příkazy menu a klávesy.
- `make-app.sh`:
  1. `swift build -c release --product MMTTY4MacApp`
  2. vytvořit `build/mmtty4mac.app/Contents/{MacOS,Resources}`
  3. Info.plist: `CFBundleIdentifier` `cz.ok1xoe.mmtty4mac`, `LSMinimumSystemVersion` 14.0, `NSMicrophoneUsageDescription`
  4. `codesign --force --sign -` s entitlements `com.apple.security.device.audio-input`
- Ruční ověření:
  - Spuštění `.app`, snímek obrazovky (`screencapture -l <windowid>`).
  - Příjem přes BlackHole z `rtty-tool gen` + `afplay`, nebo z druhé instance `rtty-tool live`.
  - Makro, log a změna nastavení.
