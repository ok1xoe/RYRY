# App Store Connect – čeština (lokalizace)

V App Store Connect přidej jazyk **čeština** a vlož bloky do polí se stejným názvem. URL a údaje o aplikaci
jsou společné, viz `metadata-en.md`.

## Název (max. 30)

```
RYRY – RTTY pro závody
```

## Podtitul (max. 30)

```
RTTY přes zvukovku podle MMTTY
```

## Propagační text (max. 170)

```
Příjem a vysílání RTTY přes zvukovou kartu Macu: osvědčený demodulátor MMTTY, bodování závodů, band mapa, DX cluster a API kompatibilní s fldigi pro váš logger.
```

## Popis (max. 4000)

```
RYRY je nativní program pro macOS na RTTY – dálnopisný provoz oblíbený mezi radioamatéry na závodech i při lovu DX. K transceiveru se připojí přes zvukovou kartu a přijímá i vysílá RTTY demodulátorem programu MMTTY (JE3HHT), který je pro RTTY měřítkem, přepsaným pro Mac.

PŘÍJEM
• Demodulátor MMTTY (IIR, FIR, PLL a FFT), AFC, ATC, squelch, zářez (notch) a LMS filtr
• Spektrum a vodopád – kliknutím naladíte, pravým tlačítkem potlačíte rušení
• Druhý dekodér a dekódování více signálů najednou
• Kliknutím na slovo v příjmu se značka, report nebo číslo zapíše do QSO

VYSÍLÁNÍ
• AFSK přes zvukovou kartu nebo FSK (klíčování přes USB sériový port)
• PTT přes RTS/DTR nebo CAT
• 16 maker s proměnnými MMTTY, sady maker pro běžný provoz, DX a každý závod, uložené zprávy a vysílací okno

ZÁVODY
• Předvolby 28 RTTY závodů (CQ WW, CQ WPX, ARRL Roundup, WAE, URC, Russian WW, BARTG, SARTG, NAQP, OK DX a další) s pravidly výměny, bodování a násobičů
• Enter Sends Message (Run i S&P), pořadová čísla, kontrola duplicit, Super Check Partial a historie značek
• Skóre a násobiče po pásmech, QTC pro WAE, export Cabrillo

BAND MAPA A SPOTY
• DX cluster a Reverse Beacon Network s filtry pásem a módů
• Band mapa se spoty a polohou rigu, spoty jako popisky ve vodopádu
• Upozornění na vaši značku v příjmu, hledané stanice a nové země

LOG
• Log čitelný každým loggerem (ADIF), import z jiných programů i z MMTTY pro Windows
• Callbook QRZ.com a HamQTH, země DXCC, azimut a vzdálenost
• Nahrávání na eQSL a Club Log; LoTW přes TrustedQSL

OVLÁDÁNÍ RÁDIA
• Vestavěný CAT pro Icom, Yaesu, Kenwood a Elecraft přes USB
• hamlib rigctld a flrig po síti

PRO VÁŠ LOGGER
• RYRY odpovídá jako fldigi (XML-RPC), takže ho ovládnou loggery jako RUMlogNG nebo MacLoggerDX
• JSON-RPC API přes WebSocket s průběžnými událostmi pro vlastní nástroje

VYZKOUŠEJTE BEZ RÁDIA
Zvolte Nápověda → Přehrát ukázkový signál a sledujte, jak RYRY dekóduje závodní spojení.

RYRY je zdarma a otevřený pod licencí GNU LGPL v3, založený na MMTTY od Makota Moriho (JE3HHT). Zdrojový kód: https://github.com/ok1xoe/RYRY

K vysílání je potřeba radioamatérská licence.
```

## Co je nového (max. 4000)

```
První vydání RYRY v App Store – programu pro RTTY na Macu, dříve šířeného jako mmtty4mac.

• Nové jméno a ikona
• 28 předvoleb RTTY závodů s přehledem pravidel, bodováním a násobiči
• Sady maker pro běžný provoz, DX a každý závod; tooltip tlačítka ukáže, co makro pošle
• Nápověda → Přehrát ukázkový signál: dekódování si vyzkoušíte i bez rádia
• LoTW: RYRY připraví soubor ADIF a otevře ho v TrustedQSL
• Přechod z mmtty4mac: nastavení se přenese samo; RYRY se jednou zeptá na přístup ke složce s logem a hesla k online službám bude možná potřeba zadat znovu
• Spouštění hamlibu aplikací bylo odstraněno – spusťte rigctld sami a zvolte „hamlib rigctld (síť)“
```
