Help with RYRY

Start with the manual – it covers the first setup, radio control, receiving, transmitting, contests and the logger API. If something does not work, the answers below solve most problems.

Frequently asked questions

I see no signal in the waterfall.

Settings → Audio: choose the input of your radio's USB sound card (e.g. “USB Audio CODEC”) and check the level in the top bar. The first time, macOS asks for microphone access – if you declined, allow RYRY in System Settings → Privacy & Security → Microphone. Without a radio, try Help → Play Demo Signal.

The radio does not transmit (PTT).

Settings → PTT / FSK: choose RTS or DTR on the serial port of your interface, or CAT PTT when the rig is controlled over CAT. The CAT port cannot be shared with PTT over RTS/DTR.

How do I control my radio?

Settings → Rig: “CAT via USB (built-in)” for Icom, Yaesu, Kenwood and Elecraft. For other radios start hamlib yourself, e.g. rigctld -m <model> -r /dev/cu.X -s <baud>, and choose “hamlib rigctld (network)”, or use flrig. The App Store version cannot start rigctld for you.

How does LoTW upload work?

Turn on LoTW in Settings → Online and click L in the Log window. RYRY saves the QSOs not uploaded yet to your Downloads folder and opens the file in TrustedQSL, where you sign and send it (the certificate and Station Location are set up in TQSL). Then confirm in RYRY and the QSOs are marked as uploaded.

Where is my log?

In the folder shown in Settings → API and log (by default ~/Documents/RYRY): a JSONL file and an ADIF file any logger can read. macOS lets RYRY into a folder only after you choose it, so RYRY asks once and remembers the access. If you refused, the log is inside the app's container – the message in the status bar says where.

I used mmtty4mac before. What happens to my settings?

RYRY is the new name of mmtty4mac. On the first launch your settings move over automatically, and RYRY asks once for access to your log folder (usually ~/Documents/mmtty4mac). Passwords and API keys for online services are stored in the Keychain and may have to be entered again.

My logger does not see RYRY.

Choose “fldigi” in the logger: RYRY answers fldigi's XML-RPC on port 7362. Check Settings → API and log that the fldigi API is on. By default it listens on this Mac only.
